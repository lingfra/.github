# lingfra

🔨 _providing a toolbox for your own customized infrastructure_ 🚀

## platform support

</div>

Currently, most of this collections are only tested on [Arch
Linux](https://archlinux.org/). However, they should be generic enough to run on
any distribution. I would love to support _all_ major distributions, but I don't
have the time. If you find the content of this organization interesting and you
want to make it compatible with your favorite distribution, please do not
hesitate to open issues and pull requests!
